# 主题校验：独立分句中的“与……无关”

本项是独立候选修复，不与卡片出处显示或映射规则发布捆绑。

## 范围

已有真实诊断记录中，低分、中性理由使用“与 A 股宏观流动性无关”，
却因为其中的“流动性”触发正向主题锚定要求。该判断不是外部新闻事实核验，
诊断样本也不是人工 Gold、总体误拒率或模型准确率。

只在现有 `strip_explicit_theme_denials` 中识别完整独立分句：

```text
与 [A股][宏观] <已有主题 marker 或 marker 列表> 无关
```

分句必须从文本开头或现有标点边界开始，以边界或文本结尾结束。
允许横向空白，不使用任意文本通配符，不跨行连接。
“并非与……无关”、跨句片段、无关紧要及其他不明确说法不享受新增豁免。
原先的前置否定处理保持不变。

调用方的范围不变：只有不高于 4 分的中性**理由**允许去除这种否定提及；
正向 tag、高分或非中性结果没有被放宽。来源中的明确否定也不能反过来
为模型的正向主题断言提供锚点。前后分句、转折后的主题断言和其他独立
事实校验必须继续保留。

两条来源回归只要求解除这一个主题误拒。也门样本仍会触发独立的数字
上下文校验，不能把主题修复宣称为整条评分完全通过；本项不修改该校验。

## 策略身份与历史

`core/score_evidence.py` 已纳入 `core.config._strategy_code_fingerprint()`。
因此本修改会自动改变评分策略指纹，即使配置、模型、prompt 和阈值完全不变。
现有指纹测试覆盖 helper 字节变化影响身份的行为；禁止手工维持旧指纹。

新旧契约的评分分开统计。不得重写历史 score path、补造旧证据或自动重评分
来降低中性比例。历史记录继续保留原策略身份。

本候选只完成本地正反例与相关测试；尚未通过完整 Linux release gate，
没有构建、部署或刷新。若决定上线，应使用独立的正常发布窗口和既有门禁，
不追加到正在验收的其他镜像中。

## 低分中性理由：整句否定范围（扩展）

09-12 私有证据批次离线回放显示，Kimi 低分中性理由常以提示词关注范围作否定说明，
如“与A股宏观流动性**及政策**无关”“非国家级政策或流动性事件”“不涉及A股流动性”
“无央行政策、社融异常……”“与AI芯片算力等科技产业无关”，其中的主题词触发了
主题锚定误拒，最终被替换为固定安全中性 4.0。

新增 `strip_low_score_denial_clauses`，**仅**用于不高于 4 分且中性的理由；
tag、来源文本、高分或非中性结果不受影响。整句（标点边界之间）必须完整匹配下列
有界形式之一才会被移除：

```text
[且/并/也/均] 与|和|同 <有界名词列表> 无关|无直接关联|无直接关系|无关联
[且/并/也/均] 对 <有界名词列表> 无[直接|明显|实质]影响|关联
[而/并] 非 <有界名词列表> 事件|政策|消息|范畴|主线|题材|催化|制度|影响|映射……
[且/并/也/均] 不涉及|未涉及|未涉|不属于|不包含 <有界名词列表>
[且/并/也/均] 无|并无|没有 <有界名词列表> 事件|政策|异动|影响|信号……
<主语> 与 <有界名词列表> 无关   （只移除“与……无关”尾部，主语保留并继续校验）
```

有界名词列表不含标点，最长 60 字。分句中出现转折（但/却/而是/然而/不过/只是/仍）、
“有关/相关”、双重否定（并非与/不是与）或正向变化谓词（改善/宽松/释放/利好/提振/
提升/增加/上升/增长/回暖/充裕/放水/扩张/加码/突破/大增）时一律不移除。
“非农/非银/非常/非标……”“无人机/无线/无疑/无论/无风险……”不视为否定。
移除后剩余理由仍须通过原有主题、事件与数字校验。

离线回放（同一批 892 次首轮输出，无模型调用）：master 与本修改相比，
106 次 Kimi 主题拒绝不再是主题拒绝（78 次通过，28 次随后仍被数字/事件校验拒绝），
0 次原通过改为拒绝，SiliconFlow 结果不变。逐条已人工核对均为否定说明。
这不是总体误拒率估计。策略指纹随 `core/score_evidence.py` 变化自动更新（见上文）。

## 收紧：只剥离否定范围本身（修复 #170 吞掉后续肯定断言）

#170 的整句匹配中，`不涉及{范围}` 没有结尾限定，范围字符集又包含任何汉字，因此
“不涉及AI并且央行降准”整句被当作否定删除，编造的“降准”不再受主题校验。现改为：

- 否定范围不得跨越开启新断言的连接词（并且/而且/同时/另外/此外/以及/随后/其后/但/但是/
  然而/不过/而是/只是/且/并/而/却/又/还；并购/并网/偿还等名词除外）。
- 句内遇到连接词时，只删除连接词之前恰好构成完整否定式的部分，连接词及之后的内容原样保留
  参与主题校验；若其后本身也是完整否定（“不涉及X且与Y无关”），一并删除。
- 范围内出现宣告/动作动词（宣布/表示/称/发布/出台/决定/批准/实施/启动/下调/上调/将/拟/已/
  正在/计划…）、正向变化词、“有关/相关/无关”或“并非与/不是与”双重否定时视为歧义，整句保留
  （失败即关闭）。

离线回放（09-12 批次 892 次首轮输出，对比 master 4e4b435）：0 次翻转；全部低分理由的剥离结果
与 master 逐字一致，原 78 次恢复全部保留。

### 封闭式与开放式否定

- **并列与新断言**：以及/及/和/与/、/或 后接名词短语只是扩展被否定的对象列表；并且/而且/同时/
  另外/此外/随后/但/然而/不过/而是/且/并/而/却/又/还 等才开启新断言（其后内容保留参与主题校验）。
  列表分隔符之后若是“主体+动作”谓语（央行降准、公司回购、外资买入…），视为新断言，整句保留。
- **封闭式**（与X无关/无直接关联/没有关系、对X无(直接)影响、“主语与X无关”）：有显式关系结尾，
  直接剥离 X，不做多主题/事件计数；但 X 仍不得含连接词、宣告/动作动词、正向变化词或双重否定。
- **开放式**（不涉及/未涉及/不属于/不包含 X，非/无 X+泛化类别词）：X 按列表分隔符切成条目，每条
  不超过 12 字、至多命中一个主题组（`core/scorer.py` 的 `_DENIAL_SCOPE_THEME_GROUPS`）或一个事件词，
  且分隔符后的条目不得是谓语；否则视为范围不确定，整句保留（失败即关闭）。

测试经由生产入口（原始 JSON → `Scorer._parse_score_result` → `_score_grounding_verdict`）断言最终判定。
09-12 批次中 100 个被剥离的否定句全部保持剥离，0 次翻转。

## 显式“无信息”否定与双重否定（修复 37ffd6a 用户复现）

低分中性理由中的显式“无信息”说明按开放式否定处理（严格条目检查，与上节相同的门控：仅低分、中性、
非正向标签）：

- 支持形式：`无/没有/并无/未见/未提供/缺乏 [新增] X [增量|新增|相关] 信息`，例如“无AI增量信息”
  “无新增AI信息”“未见AI相关信息”“无宏观政策或流动性增量信息”。
- X 必须通过开放式条目检查（每条至多一个主题组、不含谓语/宣告动词/连接词）；“信息”二字本身不带来
  任何豁免，含肯定内容（“有AI增量信息”）或后接新断言（“无AI增量信息，但央行降准”“…并且央行降准”）
  时其后内容照常参与主题校验。
- 双重否定（并非/不是/绝非 + 没有/无/未见/未提供/缺乏/不涉及/不属于/与…）表示肯定，无论旧的
  内联“没有X”规则还是新规则都不剥离（失败即关闭）。旧内联规则同样作用于来源文本，因此来源中的
  “并非没有X”现保留 X 作为主题锚点（语义更正确）。两个否定词之间允许任意空白（半角空格、制表符、
  全角空格 U+3000），两层规则（分句剥离与旧内联“没有X”规则）判定一致。来源中保留的只是该主题锚点，
  其后的事件断言（如“尚未获得订单”）仍按原事件/数字校验。
- 有限尾句修复：另允许两条已确认的字面形式“非宏观流动性焦点”“无宏观政策增量”，但只在
  **最终独立分句**使用，不把“焦点/增量”加入通用否定类别，不推断其他主题或省略形式。
  句末标点保留；正文前面的主题、主体、数字、单位、方向、计划和否定继续走原校验。
  “无宏观政策增量但央行降准”“无AI宏观政策增量”“并非无宏观政策增量”、带主体或数字的变体
  均不匹配，后面另有分句时也不匹配。“无新增宏观信号”等其他说法仍按原规则处理。
  新回归通过完整评分校验入口断言结果。两条旧完整输出还有其他数字/归属差异，仍拒绝；
  不能把解除主题误拦说成这两条历史新闻已获准。评分格式约束（换行、Tab、末尾空白）也不放宽。
