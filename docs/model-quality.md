# 模型质量与数据契约

## 首页：处理状态、解释质量与市场研究分开

首页先显示当前评分契约的近24小时处理汇总，以及需登录的保守处理记录入口。
处理汇总复用已有诊断，由 worker 在生成模型质量快照时读取，只公开白名单计数；
不包含文章、后端/模型身份、原始响应、错误详情或凭据。公开页面不因此新增数据库
查询或模型调用，`/score-quality` 的鉴权保持原样。

调用次数、校验尝试次数与基础评分账本记录数是三种单位，不能拼成通过率漏斗。
调用成功不等于解释正确；已记录的保守处理不等于拒收合理。没有观测到记录显示零条，
读取失败显示暂不可用，未接入或契约不匹配显示未知；没有人工核对结果时不使用统计
替代解释质量结论，也不推断其它地方不存在人工核对。

处理汇总按评分策略、评分时间查询，排除相似副本，不按映射版本拆分。市场研究仍
采用原有评分策略 × 映射版本与研究窗口。保守处理入口沿用固定当前契约、近24小时
**收录时间**、现存缓存、最新50条的口径；它不是汇总数字的逐行明细。不携带密钥，
不混入历史，不改变目标页筛选。

默认90天的完整页和简版页在快照模式下复用同一份 worker HTML。原有详细市场指标、
历史比较、样本条件和调参研究资格保留在默认收起的研究区，不再代表整个模块质量。
自定义研究窗口及 JSON 接口保持原语义；没有后台处理汇总的实时研究视图明确显示未知，
不为补齐数字进行额外现场查询。旧快照不会被本次代码自动改写，下一次自然生成后生效。

本次只改变显示与快照组装：不改评分、统计规则、阈值或数据契约，不新增表或审核系统。
新闻语义核对不需要等市场样本门槛满足；下方市场研究回答两个独立问题：

1. AI 评分与方向在后续市场数据中是否呈现稳定的历史关联；
2. 事件到 A 股个股的映射，在冻结当时关系后是否得到市场侧后验支持。

它不回答“AI 是否导致上涨”，也不直接生成可执行交易策略。所有建议默认
`auto_apply=false`。

## 1. 冻结时点信号

`backtest_signals` 在正常生产写路径下是追加式修订账本。每条信号保存稳定事件
UUID/版本、分数、方向、入选状态、评分路径、策略版本、映射版本、市场代理和实际
可用时间；显式迁移和有界保留治理不应被误解为整张表具有数据库级不可变属性。

`backtest_signal_securities` 在每条新信号账本修订写入时，冻结该次事务解析出的真实股票
映射 ID 与修订；正式映射后验只使用 `selected=1`、非相似副本的冻结集合。自动事件修订
可以继承上一版冻结集合；没有冻结集合的旧信号保持“未冻结”，系统不会用今天的映射
反向补写过去。

后验计算只读取信号当时可见且随后到期的数据。文章发布时间、抓取时间、评分时间、信号
可用时间和行情源时间分别保存，不能互相替代。

### 分数解释与未知值

缓存与信号账本为新评分保留以下六个可空字段，仅解释既有分数，不参与决定评分路径、
阈值或入选规则：

| 字段 | 含义 |
| --- | --- |
| `raw_score` | 本次实际采用的评分来源，在后续分数限制、时效或事件雷达调整之前的分数；来源可能是模型或本地路径，不统一冒充模型原始分数。 |
| `score_adjustment` | 最终保存的 `score - raw_score`，为净调整量，不是每个调整步骤的完整记录。 |
| `score_margin` | 最终保存的 `score - score_threshold`，保留正负号；负值表示低于冻结的通过阈值。 |
| `stage1_stage2_delta` | 采用 Stage 2 且两阶段模型与分数可确认时的 `stage2_score - stage1_score`；缺一阶段或属于本地降级时未知。 |
| `fast_pass_hint_score` | 本次确实产生的 FastPass 提示分数；提示不等于实际采用的最终分数。 |
| `score_threshold` | 本次文章评分使用的冻结通过阈值，不是通知阈值或事件雷达聚合阈值。 |

旧数据没有这些证据时全部为 `NULL`，包括冻结阈值；`NULL` 表示未知，而数值 `0` 是真实
的零差异或零分。读取旧缓存、旧账本时不把未知改成零，也不使用今天的配置补算过去。
摘要去重时，这六项随完整评分结果的拥有者一起复制；较新的链接或发布时间不能带入
另一篇稿的分数解释，旧评分结果也不会借用新稿的诊断。

遗留字段 `score_confidence` 并不是模型正确概率、预测胜率或收益概率。现有评分路径
在正常 LLM 评分分支中，使用的是后续 cap/time 调整前距当时通过阈值的归一化绝对距离：
`min(1, abs(raw_score - pass_threshold) / 3)`；保守中性、显式本地规则等分支保留原有
零值。它无法区分“高于阈值”与“低于阈值”，也不能代替新增的有符号
`score_margin`。本轮保留其历史数值和既有统计语义，不重写历史、不强行校准为概率。

旧 `quality-salvage-provenance-v1` bridge 工件继续按原字段契约读取，原 output/evidence
hash、资格分类与 run ID 不变。该版本没有上述六项证据，因此仅在返回的诊断说明中标记
`score_explanation_diagnostics.status=unknown`，六项均为 `None`；即使当前实时账本已有
新字段，也不能据此恢复旧工件未冻结的依据。这种“诊断未知”不等于更改原 bridge 的
eligible/ineligible/unknown 资格结果。未来若要扩展工件字段，必须另行版本化，不能给
v1 新增必填列或改写既有工件及哈希。

`two_stage_scoring` 配置现纳入策略指纹；两阶段配置变化不会误复用旧契约的缓存。
按照项目既有规则，评分代码变化也会产生新的策略身份：历史样本继续保存并可单独查看，
但不会自动并入新契约的模型质量样本。上述解释字段变更本身未调整模型、提示词、
FastPass 决策或 Quant 对外协议，也未增加页面评分指标。

### 持仓关注提示与 FastPass

持仓只说明“这条新闻值得我关注”，不说明新闻是利好、利空，也不保证投资价值。
`fast_pass.tiers` 中名为 `watchlist` 的规则，以及旧 `fast_pass.watchlist` 配置，
都只产生中性的关注提示；即使遗留配置写了 `skip_llm: true`，也不能因持仓命中
直接采用规则高分或绕过模型。低分、负面新闻和模型保守中性结果仍沿用原处理规则，
不会被持仓提示抬分或改成看多；既有本地拒收与其他过滤流程也不因此关闭。

持仓代码按六位证券代码的完整边界匹配，支持常见 SH/SZ/BJ 前缀及 `.SH/.SZ/.BJ`
后缀，不匹配长数字或无关英文字母标识中的子串。这里的代码匹配仅用于关注提示，
不替代上市身份、资产关系或方向证据核验。

普通 FastPass 规则未显式配置 `skip_llm` 时也只作提示，分层规则不继承全局的跳过
开关。只有非持仓规则自身明确配置 `skip_llm: true`，才沿用独立的 `fast_pass`
评分路径；旧顶层 `keywords` 的显式开关仍适用于该顶层规则。匹配顺序和按 feed
关闭 FastPass 的机制保持不变。

提示分数可以记录为 `fast_pass_hint_score`，但不等于最终采用的分数或方向。
若最终为 safe-neutral 等非实质路径，六项分数解释继续为 `NULL`；本次不改评分模型、
模型提示词、数据库或 Quant 协议。此项持仓语义修正与前述纯解释字段变更分开交付，
并按既有策略指纹规则区分新旧契约，不改写历史信号。

## 2. 评分后验

正式评分后验使用当前精确“评分策略指纹 × 映射版本”契约下的生产入选信号。安装完全
没有信号账本历史时，只展示明确标记为 `legacy_news_cache` 的短期预览；已有其他契约
账本但当前契约尚无样本时保持正式快照视图为空，不混用旧契约或短缓存。该预览不能推进
正式优化门控。描述指标包括：

- 72 小时主题复现；
- 映射资产及基准的 T0、T+1、T+2 方向关联；
- 目标日单日毛收益与毛超额；
- 分数桶、主题、独立事件和独立结果日覆盖。

T0 是目标交易日收盘相对前收的完整日变化，仅允许 15:00 前已经可用的信号进入。
T+1/T+2 表示相应目标交易日的单日变化，不是从信号时刻模拟成交的持有收益。

72 小时主题复现从信号实际可用时间起算，只对截至本次评价时点已完整观察 72 小时的
成熟样本计算复现率。复现须发生在信号之后且不超过 72 小时；未满观察窗口的信号单独
计为“待观察”，不进入该复现率的分子、分母，也不记为未复现。待观察信号仍可作为
较早成熟信号的后续主题观察。

价格方向与收益统计至少需要 30 个样本和 30 个独立结果交易日；72 小时主题复现至少需要
30 个成熟样本和这些样本覆盖的 30 个独立信号自然日，否则只显示“待积累”。统计展示
与调参研究的样本资格分别判断：某项指标达到展示门槛即可展示，无须等待调参研究就绪。
调参研究沿用更严格的现有门槛：至少
100 个独立事件、60 个独立结果交易日、80% 行情代理覆盖，并且需要已经独立结算的
入选/未入选全分数对照。上述 30/30、100/60 门槛不因观察窗口修正或展示文案调整而降低。

独立对照只在正式生产查询中计算：系统一次读取当前精确契约下最终修订、非相似副本的
全分数账本，先在全部信号中按“稳定事件 × T+1 结果日”选取全局最早代表，再按代表信号
写入时冻结的 `selected` 状态分成入选臂和未入选臂。两臂使用同一评价时点、同一交易日
口径，并且只接受资产与上证指数代理都具有不可变行情修订 ID 的精确 T+1 价格；缺失时
不顺延。两臂都达到 100 个独立事件、60 个独立结果交易日和 80% 行情代理覆盖后，对照
才可为候选调参研究提供 ready 信号；仍然不会自动修改阈值。

评分的“调参研究样本条件满足”和映射的“候选优化”表示样本具备开展候选研究的资格，
不表示模型质量及格、策略已经有效，也不表示可以发布。资格不足也不意味着模型质量
不合格；它说明当前可比、已结算的数据还不足以支持相应研究。

显式 `min_score=0` 或自定义阈值查询属于探索视图。它可以展示全分数分布，但其样本不会
推进正式优化门控，也不能单独取得候选调参研究资格。

页面的资格漏斗按同一次精确契约结果派生，分别展示账本信号、入选/未入选分析样本、
正式映射对和到期事件结果。它们是不同计量单位，不能串成一条流失率，也不会把历史
契约合并进当前分母；资格过滤只解释样本去向，不代表删除数据。

## 3. 个股映射后验

正式个股映射只包含信号时冻结的 `direct`、`upstream`、`downstream` 和 `ecosystem`
真实股票关系。`concept`、指数、ETF 和市场代理不进入正式方向有效性分母。

`event_outcomes` 使用 `signal_available_at` 之后首个预定交易日的 15:00 收盘作为归因
基线；该日资产或沪深 300 端点行情缺失、无效时不结算，也不会自动顺延。系统在
T+1/T+3/T+5/T+20 记录相对沪深 300（`sh000300`）的累计收盘到收盘毛超额。行情修订
追加保存；当前结果同时绑定端点价格修订，旧版本不会被静默覆盖。

“已结算”要求个股与沪深 300 在基线日、目标日的四个端点都有真实收盘证据：价格为
有限正数，行情源时间属于精确目标交易日、按上海时间不早于 15:00，且不晚于结果生成
时点。盘中价格、缺失或未来时间不能充当收盘价；不以人工补出的 15:00 代替源时间。
页面的“收盘字段完整”和正式映射质量统计采用相同要求。旧结果若引用了不合格的端点，
原始数值保留供审计，但不算正式完整收盘结果或历史命中；未到期、真实缺价和负收益仍
如实保留。本要求不改收益公式、评分策略或映射规则，也不自动改写历史数据库。

映射描述指标的最低发布门槛为：

- 已结算方向样本不少于 30；
- 独立事件不少于 30；
- 独立结果交易日不少于 30；
- 已结算证券不少于 10。

进入“候选优化”的门槛为：方向样本 100、独立事件 100、结果日 60、证券 10，且当时
映射证据覆盖率至少 90%。候选仍须人工语义抽检、按结果日分块的留出验证和影子验证。

证据覆盖只说明当时存在支持关系的材料，不代表映射语义正确。真正的准确率/召回率
（precision/recall）需要独立人工标注集。

### 双周期投资辅助

双周期视图复用既有事件雷达与 `event_outcomes`：短线观察 T+1/T+3/T+5，波段观察 T+20。
同一事件可同时查看两种视角，沿用原评分、模型和 prompt，不生成短线分或波段分，也不
自动买入。核对点及撤回关注条件均为待人工核对清单，不代表事实已确认或条件已经触发。
市场结果仍以 `signal_available_at` 之后首个预定交易日的 15:00 收盘为归因基线，
不以新闻发布时间或真实进场时间起算。毛收益、毛超额（gross）不是可实现净收益，
不包含手续费、滑点及实际成交约束。本视图不创建新数据库或独立系统。

概览和市场反应页另提供“消息类型（标题级提示）”，只使用与当前事件标题匹配的
支持性原文标题，不使用生成摘要或后续收益：

- 新催化候选：标题包含订单、合同、公司公告等可核对事项；首发时间、是否超预期、
  是否已被价格消化和能否交易均未确认，候选也不等于利好。
- 已涨跌复述：描述已发生的股价或板块表现，不预测下一周期同向涨跌。
- 催化与行情混合：同一标题同时出现两类信息，需要分别核对。
- 政策、宏观或观点背景：不直接确认个股传导。
- 信息不足：原文绑定不完整、证据存在反驳，或标题有预测、旧闻等歧义时保守保留。

这些提示仅描述当前标题，不给整个合并事件定性，也不改变分数、方向、入选状态、
映射、结果统计或现有契约。不新增模型、数据库或发布/审核门禁。

### 实时新闻卡片的解释出处

实时卡片的“主题背景（规则生成）”来自标题匹配的本地主题模板，不是模型给这条新闻
打分的理由，也不代表逐条核验了原文事实。“规则池示例”仅用于解释主题范围，不证明
这些公司被本文提及或已经受益；空示例显示“未提供个股示例”，不推断为行情缺失。
模板只展示一次；未知主题继续显示“暂无可信映射”，不以模型理由补出股票。
这项展示修复不改变分数、方向、入选条件、映射规则或历史结果，也不表示现有评分
已经改造成阅读优先级分数。新闻研究工具是产品方向，不能仅靠标签改名宣布评分转型完成。

## 4. 契约与版本隔离

评分后端的失败降级与 Token 记录口径见 [scoring-call-budget.md](scoring-call-budget.md)：
语义失败先尝试下一后端，再以明确的本地身份保守处理；不通过付费复制固定 JSON 修复评分。

正式质量结论绑定“评分策略指纹 × 映射版本”。评分后验只读取当前精确契约对的信号，
映射后验也按契约对独立分组；系统禁止跨契约合并胜率或收益。当前契约直接展示，历史
账本保留但默认折叠，评分页不会自动逐个重算所有历史契约。

启用动态反馈示例时，反馈提交时可见的文章字段冻结在
`feedback_example_snapshots`；实际参与某次评分的有序反馈 ID 与冻结字段保存在
`scoring_contract_snapshots`。其 SHA-256 profile 摘要会进入有效
`scoring_strategy_version`，反馈集合变化即建立新队列。

模型质量缓存键同时包含有效评分策略和映射版本。请求计算期间若反馈指纹变化，缓存以
实际计算结果返回的策略版本为准；无法识别契约时安全绕过缓存。

## 5. 收益和统计限制

- 页面中的收益为收盘到收盘毛收益，价格变化自然包含隔夜跳空；但不含手续费、滑点，
  也不模拟跳空入场价、停牌、涨跌停和实际成交约束。
- 收盘观察是归因口径，不是成交价格。
- Wilson 区间没有自动消除同一结果日跨事件相关性；候选规则仍需按结果日分块验证。
- 当前 MFE/MAE 不计算并始终为空；未来只有完整路径行情修订全部冻结后才有资格启用。
- 历史关联不证明因果、荐股能力或未来可重复性。

## 6. 研究资格与人工验证

评分调参研究路线：

```text
调参样本待积累 → 入选样本达标，对照待补齐 → 调参研究样本条件满足 → 影子验证 → 可发布
```

映射研究路线：

```text
样本不足 → 候选优化 → 影子验证 → 可发布
```

这些箭头说明研究资格和后续人工验证的顺序，不新增自动状态机，也不作为质量评级。
统计指标是否可展示仍按第 2、3 节的描述门槛独立判断。评分路径复用现有
`insufficient`、`posterior_ready`、`candidate` 资格结果：分别表示研究样本尚未充分、
入选后验达到研究样本门槛但对照尚未就绪、入选后验和两条独立 T+1 对照臂均达到候选
研究门槛。映射路径同样复用现有候选资格。两条路径的语义抽检、留出验证、影子验证与
发布仍由人工完成；系统不会自动更改评分阈值、来源标准、主题规则或个股映射。
