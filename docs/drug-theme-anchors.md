# 创新药主题：临床阶段来源证据（独立修复）


“临床”“新药”是创新药主题的 marker，但来源锚点原先只含“创新药/新药临床/1类新药/ADC”等，
不含“临床试验”“Ⅲ期临床”。因此来源写明“XX联合疗法Ⅲ期临床试验完成首例入组”时，
模型以“创新药”为 tag 仍被判为主题无锚。

新增 `_INNOVATIVE_DRUG_EVIDENCE_ANCHORS`，只扩充**来源侧**锚点：
`临床试验`、`临床研究`、`期临床`（覆盖 Ⅰ/Ⅱ/Ⅲ、Ib、一/二/三期；NFKC 把 Ⅲ 折叠为 III）、
`IND申请`、`IND获批`、`NDA申请`、`BLA申请`。marker 集合不变，因此不会对任何理由新增
锚点要求（只可能把拒绝变为通过）。未采用单独的“临床”（临床医生等）、裸 `NDA`（保密协议）
或“上市申请获受理”（IPO）。未加入公司到行业的映射锚点（需证券主数据，误映射风险不小）。

## 收紧（修复 #171 过宽锚点）

#171 的裸子串 `期临床` 会命中“假期临床医生”“长期临床实践”，`临床试验/临床研究` 也会
在器械或一般医学研究中锚定创新药主题。现改为：

- 来源字符串锚点只保留 `IND申请/IND获批/NDA申请/BLA申请`（及原有创新药锚点）。
- 显式试验分期（`_DRUG_TRIAL_PHASE_RE`）：罗马 I–IV（Ⅰ–Ⅳ 经 NFKC）后接“期临床/期试验/期研究”；
  Ia/Ib/IIa/IIb 等亚型可单独“Ib期”；阿拉伯 1–4（可带 a/b）与 一/二/三/四 须接“期临床”；
  支持 I/II、1/2 形式。分期前必须是数字，故 假期/长期/早期/定期/近期/周期 不会命中；
  第/十/年/卷 等前缀排除期刊或班次（第三期、十三期、2025年3期）；“III期肺癌”（肿瘤分期）不命中。
- 泛化“临床试验/临床研究”只在**同一句**内有药物证据（药/单抗/抗体/疫苗/分子/靶点/适应症/
  注射液/胶囊/疗法/ADC/IND/NDA/BLA）且全文无器械/诊断语境（器械/设备/支架/诊断/试剂/耗材/
  仪器/导管/植入/流行病）时才算锚点；不确定则不锚定。来源中“不涉及临床试验”等否定先剥离。
