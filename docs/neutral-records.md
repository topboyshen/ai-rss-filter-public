# 保守处理记录：实际查看入口

模型质量页面（Glance `/quality`，包括首页简版统计）概览区包含默认收起的
**保守处理记录**。展开后点击 **查看记录（需后台登录）**，进入：

`https://ai.example.invalid/dashboard/neutral-records`

沿用后台 HTTPS 登录；登录成功后回到记录页。链接不携带 API key，页面无需
JavaScript 或 iframe。不调整 Glance 配置、默认流筛选、评分或模型。

## 显示什么

- 当前评分契约精确匹配，最近24小时**收录**的现存 `news_cache` 保守中性记录。
- 按收录时间倒序，最多50条；多于50条明确提示截断，不展示虚假的总量。
- 标题、配置中的主订阅源、北京时间收录时间、已记录的保守处理说明。
- 原因仅来自 `safe_neutral_reason`；缺列、空值、未知值或与最终路径不一致时
  显示“具体原因未完整记录”，不根据标题、模型输出或历史路径补写原因。
- `theme`、`facts`、`contract` 是校验过程说明；`initial` 只表示初次中性且
  未记录细因。它们不是新闻真实性、投资价值或模型准确率结论。

收录时间不是首发时间或评分时间；缓存不是完整历史账本，也不是模型质量统计
分母。已清理缓存和其他契约不在本页范围。没有记录与读取失败分别显示；不可用
返回503，绝不伪装成“没有新文章”。

## 读取边界

公共模型质量片段及其快照只提供静态记录入口，不嵌入具体记录，也不查询记录数据库。
后台快照另有匿名处理汇总，但以评分时间统计基础账本决策，不是此页缓存记录数量；
入口不能写成“查看这 N 条”。汇总生成、分母与未接入状态见 `model-quality.md`。
点击并登录后，独立页面才作只读、有时限、有条数上限的查询。返回 `no-store`，
继续使用后台严格安全头。不增加表、索引、迁移、定时器或回填。

当前契约解析依赖的反馈样例查询改用只读连接，避免查看页面时创建缺失数据库或
改变旧库的日志模式；查询、排序、样例选择和契约计算保持不变。评分指纹涵盖的
核心文件未修改。

新入口依赖更新后生成的模型质量快照；已有旧快照不会被这个提交改写。无需为了
显示入口手动刷新新闻。页面展示不代表本提交已部署；上线仍需另行授权。

## 验证

测试通过真实应用HTTP入口、登录会话、隔离数据库读取和HTML响应验证记录可见，
不以“手工把一行送给渲染函数”代替用户入口。兼顾未知原因、跨契约过滤、旧库兼容、
鉴权、危险链接/HTML转义及公共快照仍不读库。测试数据不进入生产。
