# Public distribution boundary

This repository starts from a reviewed code snapshot. It does not publish the
original private Git history, private PRs, workflow logs, deployment evidence,
databases, collected articles, raw model responses, personal holdings, private
proxy configuration, or credentials. The private repository and its original
evidence remain unchanged.

- `example.invalid` and `ai.example.invalid` are reserved examples, not a hosted
  demo. Replace them only in an independently reviewed deployment configuration.
- The three `99000x` watchlist values are synthetic test/example identifiers,
  not an owner's holdings or a recommendation. Their length, matching boundaries,
  scores and no-model-bypass protection remain covered by regression tests.
- The capture directory is an example. No cohort is included. Article/model-text
  retention needs separate authorization; capture bounds and private permissions
  remain enforced, and capture does not upload data automatically.
- Runtime legacy correction approvals are empty. Nine synthetic examples are
  installed only inside tests; no production event, mapping, source URL or evidence
  identity is distributed as an executable correction approval.
- Source fixtures and short regression sentences exercise explicit behavior;
  they are not a news archive, a labelled business dataset or accuracy evidence.
- `/root/ai-rss-filter` in installation examples is a generic installation path,
  not a connection or permission to access any existing server.
- Publishing code or passing CI does not deploy an application, change a running
  image, authorize model calls, or validate old production observation windows.
  Public configuration sanitation may change strategy fingerprints; do not claim
  compatibility with a private deployment from the old version string alone.

The CI workflow uses GitHub-hosted runners. Private diagnostic records belong
outside source control; `/data/diagnostics/` is ignored narrowly, while source,
new unclassified runtime paths and the clean-worktree release gate remain subject
to review. Ignore rules do not untrack files already committed.

No new license is asserted by this notice. Preserve existing third-party notices
and resolve any license grant separately; repository visibility alone is not a
new license declaration.
