# 首页今日事件变化（可选展示）

这是事件日报的有限公开投影，不是新模型摘要。只选现有日报规则下的最多三条
重点（新增／推进／待验证）和两条澄清／更正线索；每条只展示一条支撑当前变化的
原文来源。重点保留既有六分展示门槛；真正否认／更正按日报规则不受该门槛限制，
要求澄清／问询仍受门槛限制，且明确不等于否认。报道数量不参与重要度排序。

## 内容与边界

- 卡片标题来自当前选中证据的原文标题，不把可变事件标题或模型摘要当成原文。
- 公司名只在该条可见原文证据确实点名时显示，并复用现有消歧规则；不展示主题股票池。
- 日期与截止时间按北京时间。内容按入库时间归日，不把入库时间当新闻发生时间。
- 来源链接只暴露公开、安全的文章地址；私有 feed 地址、敏感查询参数与内网地址不公开。
- 最近采集完整度和快照新鲜度分别展示；没有数据、超限、陈旧均不宣称没有事件发生。
- 历史否认是背景时继续标注，后续报道不自动推翻否认。
- 日报／周报入口保留构建时的日期／周。跨日旧快照保留内容但标 stale，不改链接冒充今天。
- 标题与变化说明在小卡上最多三行，全文及完整来源在详情／报告页；待验证、问询、
  历史否认的标签不会随摘要省略。不是受益判断、推荐、准确率或胜率证明。

### 首页重复占位边界

首页在既有排序之后、三条重点／两条更正的名额截断之前，跳过能严格核对的标题
格式重复，再按原顺序补足名额。只归一紧贴金额／比例单位的小数末尾零，以及
财务指标与数字之间可有可无的“为”字；主体、报告期、指标、数值、正负号、
比较符、单位和语气仍须一致。`±`、`∓`、`≈`、`~` 等 Unicode 数学符号按原有顺序
保留，不把正负范围或近似数值折叠为无限定的数值；同一限定符下的小数格式差异
仍可归一。原文标题、首条来源和公司提及保持同一代表记录，
不把剩下的来源或评分拼进来。日报、周报、事件身份、计数与历史行均不改变。
同组其他新证据、历史记录或否认背景的标题语义集合不一致时，也不折叠，
不能因为最新标题相同就吞掉不同事项；来源数量不参与匹配或排序。
任一参与比较的标题达到共享读取模型的 1000 字符上限时，无法确认尾部完整，
一律独立保留，不把截断后的相似前缀当成等价证据。

例如“大族激光：预计前三季度归母净利润21.2亿元-22.2亿元……”和
“大族激光：预计前三季度归母净利润为21.20亿元-22.20亿元……”可少占一个首页位置。
这不是按文本相似度或按公司名合并事件。

“长实集团辟谣：绝无此事”和“长实集团辟谣李嘉诚逝世：绝无此事”仍保持独立：
现有可信入库证据只有标题，前者没有写明否认对象，不能仅凭同公司、同日、同一句
“绝无此事”就推定同事。外部正文的一次人工核对不替代运行时可审计的匹配证据，
也不借模型摘要或存档摘录补足对象。泛化跨标题关联不在本次修复范围内。

## 实现与读取成本

固定 `/event-radar-card?limit=8` 使用既有 `event_radar` 快照发布通道。Worker 复用
日报分类与有界证据查询，只物化最终最多五条卡片。普通生产 Web 请求只读发布文件，
不查数据库、不重建日报／周报、不调用模型。构建失败不覆盖上次成功产物。

构建沿用日报当天／七日对照的行数上限；数据库忙等最多 100ms，SQL 进度检查及
Python 阶段之间共用五秒预算。Python 阶段不是可强制抢占的硬实时线程；仍需在
批准发布后核对自然快照耗时，不能把本地测试当成生产性能保证。

其他 profile（尤其事件页 `limit=30`）保留原展示。未改变评分、映射、提示词、阈值、
认证、表结构和历史行。新增公开来源是白名单字段投影，不输出模型理由、内部契约、
审计字段或后验结果。

## 安装分两部分，不自动操作生产

应用镜像更新只更新卡片实现，**不会自动更新宿主的 Glance 配置**。已有阅读首页只有
新闻、简报、市场背景时，需另审一个配置候选：

```bash
python scripts/prepare_glance_event_changes.py existing.yml candidate.yml
```

此命令只创建本地新文件（0600，禁止覆盖），不安装、不重启。它要求已存在阅读布局，
复制原事件页的 `?limit=30` extension 设置，在首页侧栏简报后插入 `?limit=8` 卡片；
认证头等连接设置保持，事件页与其他页面不变。未知 URL 查询参数、冲突卡片或布局
拒绝自动处理。相同配置幂等；阅读布局生成器再次运行会保留这张显式安装的卡片。

未来批准发布时应先审应用完整差异及候选 YAML，再按现有发布流程部署应用、核验
快照，最后批准安装 Glance 候选并验收；两者分别留回退点。仅构建镜像不能算首页上线。

## 验收清单

1. 当前规则下普通新事件／待验证事件最多三条，更正最多两条，同一事件不重复占两块。
2. 新旧标题、数字、同链接更正、旧否认转载、多条当天进展的标题／摘要／来源一致。
3. 公司名正反例、XSS、敏感来源地址不外露；合法 CLS `ai_filter_item` 身份保留。
4. Worker 真写文件 → Web 真读文件，禁止 Web 构建／查库；失败保留旧快照。
5. 跨北京时间午夜／周界、过期、采集缺口／未知状态明确，日期周链接不偷偷改变。
6. 本地桌面、901px、390px、320px 看内容、链接与溢出；真实线上验收须待单独部署授权。

本次不附带历史误关联清理、不补发新闻、不新增采集批次，也不调整筛选数量。
